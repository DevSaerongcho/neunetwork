# 뉴비분들 꼭 보셔야할 내용

### 처음 접속하고 나서 어떤걸 해야하나요?

* 서버에 입장 하신 후 튜토리얼을 진행해주세요.
* SHIFT + F 키를 통해 모든 채널에서 메뉴를 열 수 있습니다 (일부 채널 제외)
* <kbd><mark style="color:green;">**/길라잡이**<mark style="color:green;"></kbd>를 따라가며 모든 컨텐츠를 즐겨보세요.&#x20;

{% hint style="warning" %}
일부 길라잡이는 레벨 및 특수 조건에 만족해야지 즐길 수 있습니다.
{% endhint %}

* 신화 가이드북을 살펴보며 다양한 컨텐츠들을 체험해보세요!
