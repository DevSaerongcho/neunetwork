# 대기열 및 채널

### 1. 대기열

* 신화는 누 온라인과 다르게 <mark style="color:cyan;">**쾌적한 서버**</mark>를 운영하기 위해 <mark style="color:red;">**"채널"**</mark>을 도입했습니다.
* 인원이 꽉 차 있거나, 갑작스러운 동시다발 접속 하실 경우 과도한 동시 트래픽을 막기 위해\
  순차적으로 접속하실 수 있습니다.
* 먼저 대기열에 입장한 순서대로 접속하게 됩니다.

{% hint style="warning" %}
서버 재접속 또는 대기열을 나갔다 오는 행위들은 다시 처음부터 대기열에 진입해야 합니다.
{% endhint %}

### 2. 대기열 빠른 입장 (멤버쉽 혜택)

* 신화는 대기열에 기다리지 않고 즉시 접속 할 수 있는 멤버쉽 혜택을 제공합니다.

<figure><img src="../../.gitbook/assets/스크린샷 2026-05-29 오전 9.11.15.png" alt="" width="375"><figcaption></figcaption></figure>

* 플래티넘 멤버쉽 이상 부터 적용이 가능 합니다.

{% hint style="info" %}
서버 접속 우선권은 자동 패시브로 적용되며, 멤버쉽 사용 기간동안 인원상관 없이 즉시 접속이 가능 합니다.
{% endhint %}
