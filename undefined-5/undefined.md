# 🥬 채집



* 광물 또는 식물을 채집하여 다양한 물품을 제작 또는 강화 하는데 사용하는 재료 입니다.



{% hint style="info" %}
## 진행 방식

전용 채집 도구를 사용하여 대륙 곳곳에 자원(식물, 광석 등)을 캘 경우,&#x20;

**매크로 방지를 위해**, 같은 모양 아이템 맞추는 **미니게임이 시작**됩니다.
{% endhint %}

{% hint style="success" %}
## 성공 보상

미니게임에 무사히 성공하시면 자원이 온전하게 채취되어 귀중한 전리품을 획득하실 수 있습니다.
{% endhint %}

{% hint style="warning" icon="square-x" %}
## 실패 패널티

미니게임 실패하실 경우 자원 획득에 실패하며,\
해당 자원을 다시 캘 수 없는 대기 시간 (쿨타임)이 적용되니 신중하게 손끝의 감각을 집중해서 성공해보세요.
{% endhint %}

### 1. 채집 방법

* 채집은 반드시 **"채집 도구"** 로만 작물 또는 광물을 캘 수 있습니다.

#### 채집도구

<figure><img src="https://cdn.discordapp.com/attachments/1335062542732627990/1508080168755789874/2026-05-24_21.06.53.png?ex=6a1a2b5b&#x26;is=6a18d9db&#x26;hm=0b79c3cb0ef93452a3cf1d769fb89d4f4d8e7d94d74d666c6452362de2cf63b6&#x26;" alt=""><figcaption></figcaption></figure>

* 채집도구는 종류가 여러가지 입니다.
* 더 좋은 등급 일수록 채집 쿨타임은 감소하고 및 보너스 확률 그리고 채집 내구도가 올라갑니다.



#### 미니게임

* 이제 채집도구로, 맵 곳곳에 있는 식물 또는 광물을 **" 좌클릭으로 캘 경우 "** 미니게임이 시작됩니다.

<figure><img src="https://cdn.discordapp.com/attachments/1335062542732627990/1508080197587435651/2026-05-24_21.07.07.png?ex=6a1a2b61&#x26;is=6a18d9e1&#x26;hm=c32f1fc73514b5e9d53288759303278ecce407e1467bdd0f6971d7808c0afa02&#x26;" alt=""><figcaption></figcaption></figure>

* 위에 있는 모양의 꽃 또는 광물을 아래에 목록중에서 "같은걸" 찾아서 선택하시면 됩니다.

{% hint style="danger" %}
다른 식물 또는 광물을 선택할 경우 **"미니게임은 실패"** 처리 되며, 다시 쿨타임이 돕니다.
{% endhint %}



#### 미니게임 성공

* 미니게임 성공 시, 채집이 시작됩니다.

<figure><img src="https://cdn.discordapp.com/attachments/1335062542732627990/1508080266584002600/2026-05-24_21.07.13.png?ex=6a1a2b72&#x26;is=6a18d9f2&#x26;hm=2a5a1cf4aca4abc553fcbafdb7b4c7c3332e3dfec8abf27b92a3a937c3bfc85c&#x26;" alt=""><figcaption></figcaption></figure>

* 채집중에는 움직이면 안됩니다.

{% hint style="danger" %}
채집 중 움직일 경우 **"채집은 중단"** 처리 되며, 쿨타임은 돌지 않지만 다시 채집 미니게임을 시작해야 합니다.
{% endhint %}

#### 채집완료

* 채집 성공하면, 인벤토리로 보상이 들어오며 만약 인벤토리가 꽉차 있을 경우에는 우편함으로 지급 됩니다.
